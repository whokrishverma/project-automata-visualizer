Automata Visualizer

Define a DFA or NFA, process an input string, and inspect every state transition.

1. Define your automaton

Format: from,symbol,to. Example: q0,0,q1. For an NFA, add multiple lines with the same from-state and symbol to represent multiple possible destinations. This version does not include ε-transitions.
Use an empty input to test ε (the empty string). Do not type quotation marks.
